## TECHNICAL SPECS

**Export Settings:**
- Format: PNG (or JPG)
- Dimensions: 1080x1350px
- Quality: High (95%+)
- Color mode: RGB

**Canva Template Tips:**
1. Use "Instagram Post" template as base
2. Create carousel slides within one design
3. Export each slide separately
4. Name: `Slide_1_COVER.png`, `Slide_2_EMAIL.png`, etc.

**Font Recommendations:**
- Title: Inter Bold or Montserrat Bold (48px)
- Subtitle: Inter Semibold (28px)
- Body: Inter Regular (18px)
- All uppercase for titles (impact)

**Effects to Add:**
- Glow effects on neon text (use Canva's "Glow" tool)
- Subtle animations: pulsing icons, flowing arrows
- Shadows on text for depth
- Neon border glow on slide edges
